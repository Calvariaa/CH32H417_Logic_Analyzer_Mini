# 16通道200MHz逻辑分析仪 (CH32H417WEU6移植版)

![逻辑分析仪效果图](https://i.imgur.com/gLIiwBf.png)

本工程是基于[立创开源平台原项目](https://oshwhub.com/q2h2/project_bszkxrnf)的移植版本。核心变动为：**将主控芯片从CH32H417QEU6 (QFN-128) 更换为CH32H417WEU6 (QFN-68)**，并据此修改了原理图、重绘了PCB，调整了部分引脚分配。

## 项目概述

*   **核心芯片**: CH32H417WEU6 (QFN-68封装)
*   **主要功能**:
    *   **16通道数字逻辑分析仪**: 最高200MHz采样率 (需USB3.0连接)。
    *   **2通道模拟信号采样**: 最高20Msps采样率 (功能需验证，且受WEU6封装限制)。
*   **通信接口**: Type-C (支持USB3.0 5Gbps，兼容USB2.0)。
*   **PC端软件**: 兼容开源软件PulseView (配合专用上位机U3LogicAnalyzer)。
*   **原工程**: [https://oshwhub.com/q2h2/project_bszkxrnf](https://oshwhub.com/q2h2/project_bszkxrnf)

## 与原方案的主要差异

> **重要说明**：以下差异点基于原工程评论区多位开发者的讨论和实测经验总结。

| 项目 | 原方案 (QEU6) | 本移植方案 (WEU6) | 备注 |
| :--- | :--- | :--- | :--- |
| **主控芯片** | CH32H417QEU6 (QFN-128) | CH32H417WEU6 (QFN-68) | 引脚更少，布局更紧凑 |
| **封装** | QFN-128 (12.3x12.3mm) | QFN-68 (8x8mm) | 面积大幅减小 |
| **UHSIF接口** | 完整功能 | **部分功能不完整**[^1] | 仅支持大部分功能，缺少Port 5/6/7等 |
| **ADC参考电压** | 独立VREFP引脚 | **未引出VREFP**[^2] | 内部连接至VDD33A，ADC精度可能受影响 |
| **电源域** | VIO18与VDDIO可独立 | **UHSIF与HSADC共用VIO18电源域**[^3] | 模拟采样与逻辑触发电平联动 |
| **可用ADC通道** | PF8/PF9等 (独立VDDIO域) | PC2/PC3 (VIO18域) | 需修改ADC采样代码 |
| **DAC调压** | 使用DAC1 (PA4) | 改用DAC2 (PA5) | 原VIO18动态调压功能需调整 |
| **UART调试** | PA9 | PD1 | 用于输出调试信息 |
| **LED指示灯** | PB3/PB4 | PB0/PB1 | 用于指示电源、USB连接等状态 |
| **固件下载** | 支持USB/串口/IAP | **仅支持WCH-Link下载**[^4] | 需预留SWD接口 |

[^1]: 来源：CH32H417DS0.PDF注释 & 评论区开发者@芝麻臆想、@pandy_f 的讨论。WEU6封装缺少部分Port导致功能不完整，但逻辑分析仪使用的16个I/O均可用，实测功能正常。
[^2]: 来源：评论区@芝麻臆想的分析。WEU6未引出VREFP引脚，内部固定连接至VDD33A。
[^3]: 来源：评论区@芝麻臆想的分析。WEU6的UHSIF和HSADC共用VIO18电源域，而QEU6两者独立。
[^4]: 来源：CH32H417评估板说明书.pdf P11 & 评论区作者@elctr0的回复。

## 移植修改详情

### 1. 关键引脚变更

| 功能 | 原方案 (QEU6) 引脚 | **本移植方案 (WEU6) 引脚** | 备注 |
| :--- | :--- | :--- | :--- |
| **VIO18调压 (DAC)** | PA4 (DAC1) | **PA5 (DAC2)** | 用于控制DCDC输出电压，调节IO电平阈值 |
| **模拟采样通道 (HSADC)** | PF8, PF9 | **PC2, PC3** | 原PF8/PF9在WEU6封装中未引出，需修改固件ADC通道 |
| **UART调试打印** | PA9 (TX) | **PD1 (TX)** | 用于输出调试信息，波特率921600 |
| **LED指示灯** | PB3, PB4 | **PB0, PB1** | 例如：PB0-绿灯(USB连接)，PB1-蓝灯(固件运行) |

### 2. 原理图变更

1.  **主控芯片**: 替换U1为`CH32H417WEU6`，封装改为QFN-68。
2.  **电源网络调整**:
    *   **VIO18供电**: 可使用与QEU6类似的DCDC调压方案 (需将DAC控制脚改为PA5)，或简化设计为固定3.3V供电 (如采用SY8088等LDO)。**本版本采用固定3.3V方案**，以简化设计并避免WEU6电源域耦合问题。
    *   **VREFP处理**: 参考数据手册，将VREFP引脚直接连接至VDD33A (3.3V)，并增加高质量滤波电容。
3.  **ADC通道重映射**:
    *   原模拟采样通道 (PF8/PF9) 在WEU6上未引出，需改为PC2/PC3。
    *   需修改MCU固件中的ADC初始化代码，更换采样通道。
4.  **Boot模式**: 由于WEU6不支持USB/串口下载，**必须引出SWD接口** (SWCLK, SWDIO) 用于烧录固件。
5.  **Type-C适配**: 保留CH9441P用于正反插自适应。

### 3. PCB重绘重点

*   **布局**: 因芯片封装缩小，PCB面积可大幅缩减 (参考评论区@pandy_f的版本，约4x5cm)。
*   **走线**: 对16路逻辑分析仪输入信号线进行**等长处理**，确保200MHz采样时序。
*   **接口**: 建议采用2.54mm排针，方便连接杜邦线或测试钩。
*   **保护**: 可考虑在每个输入通道增加钳位保护电路 (如并联稳压二极管或TVS管)，提高IO耐压。

## 固件与软件说明

### 固件修改点
1.  **ADC通道**: 修改`HSADC`初始化代码，将采样通道从PF8/PF9改为PC2/PC3。
2.  **DAC调压**: 如保留VIO18调压功能，需将DAC输出脚从PA4改为PA5，并修改相应控制逻辑。
3.  **LED控制**: 修改GPIO初始化代码，将LED控制引脚从PB3/PB4改为PB0/PB1。
4.  **UART调试**: 修改串口初始化代码，将UART TX引脚从PA9改为PD1。

> **注意**：本硬件修改不改变PC端软件 (U3LogicAnalyzer/PulseView) 的使用方式。

### 固件烧录流程 (重要)
1.  使用WCH-Link，通过SWD接口烧录**IAP固件** (V3F内核)。
2.  将逻辑分析仪通过USB连接至PC。
3.  打开PC端软件`U3LogicAnalyzer`，使用“帮助-固件升级”功能，烧录**APP固件** (V5F内核的.bin文件)。
> **提示**：烧录IAP后SWD接口可能被禁用，如需再次烧录，可能需要执行“全片擦除”操作。

## 已知问题与注意事项

1.  **USB3.0稳定性**: 评论区有开发者反映WEU6版本USB3.0在一个方向上可能降速为USB2.0，推测与焊接或PCB layout有关，需留意。
2.  **模拟采样联动**: 因WEU6电源域耦合，使用模拟采样时，VIO18电压 (影响逻辑触发电平) 会被限制在3.3V附近。
3.  **功能验证**: WEU6版本的逻辑分析仪功能已验证正常，但模拟采样功能需自行测试并可能调整固件。
